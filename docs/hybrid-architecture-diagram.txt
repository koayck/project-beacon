                        ↓
        ┌────────────────────────────────────────────────────┐
        │ Orchestrator: execute_navigation_sequence()        │
        │ (Pure Python — No LLM, Deterministic)              │
        │                                                    │
        │  for attempt in [0, 1, 2]:                        │
        │    route = await plan_route(...)   ← API call     │
        │    if route.success:                               │
        │      for wp in route.waypoints:                    │
        │        await move_drone_to(wp)     ← API calls    │
        │      return NavigationResult.success()             │
        │                                                    │
        │  All retry logic, error handling built-in         │
        └───────────────┬────────────────────────────────────┘
                        ↓
        ┌───────────────────────────────────────────────────┐
